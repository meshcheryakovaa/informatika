# Информатика

122 страницы учебных материалов с поиском и скрываемым левым меню.
Кнопка «Меню» сворачивает и открывает навигацию. На компьютере выбранное
состояние запоминается. На телефоне меню изначально закрыто; его можно закрыть
выбором страницы, нажатием вне панели или Escape.

## Готовый файл

В разделе [Releases](https://github.com/meshcheryakovaa/informatika/releases/latest)
скачайте `informatika_all_in_one.html` и откройте в браузере. Установка и сервер
не нужны. Изображения, стили и шрифты формул встроены в HTML. Внешние ссылки
в учебных материалах требуют интернета.

## Сборка

Нужен Python 3.10 или новее, без сторонних библиотек:

```sh
python scripts/build.py
python scripts/check.py
```

Результат: `dist/informatika_all_in_one.html`.
Для просмотра достаточно открыть этот файл в браузере.

## Исходники

- `src/index.html` — оболочка и навигация, маркер `<!-- PAGES -->` для сборки.
- `src/pages/000.html` … `121.html` — содержимое отдельных страниц.
- `src/notion.css` — стили учебных материалов.
- `src/shell.css` — интерфейс и адаптивное меню.
- `src/katex.css` — локальные стили формул KaTeX.
- `src/app.js` — навигация, поиск и управление меню.
- `src/assets/`, `src/assets.json` — изображения, шрифты и их MIME-типы.
- `scripts/build.py` — сборка единого HTML стандартной библиотекой Python.

При добавлении изображения сохраните его в `src/assets/` с именем из 24
шестнадцатеричных символов (начало SHA-256), добавьте MIME-тип в `assets.json`
и используйте путь `assets/имя.png` в HTML. Сборщик встроит файл автоматически.

## Автоматическая сборка и релиз

GitHub Actions проверяет и собирает HTML при push в `main` и в pull request.
Результат доступен как артефакт `informatika-html`.

Чтобы опубликовать новую версию:

```sh
git tag v1.0.1
git push origin v1.0.1
```

Workflow сам соберёт HTML, создаст GitHub Release и прикрепит готовый файл.
Также можно запустить **Actions → Build and release HTML → Run workflow**:
оставьте `tag` пустым для сборки или укажите новую версию для публикации.

Исходные учебные материалы сохранены из предоставленного HTML.
Лицензия сторонней библиотеки формул: [THIRD_PARTY_LICENSES.md](THIRD_PARTY_LICENSES.md).
