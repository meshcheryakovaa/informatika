Слияние документов

Слияние применяется для создания однотипных документов (писем, наклеек, конвертов и т. д.), которые рассылаются большому количеству получателей.

Для осуществления слияния необходим источник данных (таблица Word, Excel, Access или любая другая база данных).

Для выполнения слияния предназначена вкладка ленты Рассылки (рис. 23).

Рассмотрим процесс создания писем.

Подготовка источника данных

1. В текстовом процессоре Word создайте таблицу, которая будет служить источником данных для слияния (табл. 6).

2. Заполните таблицу произвольными данными

3. Сохраните получившийся документ в своей папке с именем Источник данных и закройте его.

Основной документ и подключение данных

4. Создайте новый документ с именем Основной документ.

5. В данном документе наберите текст (рис. 24)

6. К основному документу необходимо подключить созданную ранее базу данных. Для этого выполните команду:

вкладка ленты Рассылки ►панель инструментов Начло слияния ► кнопка Начать слияние ► команда Письма

7. Для подключения источника данных выполните команду:

кнопка Выбрать получателей ► кнопка Использовать существующий список ► указать
файл источника данных.

Поля слияния и просмотр результатов

8. Для окончательного оформления образца письма необходимо вставить поля слияния, используя кнопку ВСТАВИТЬ ПОЛЕ СЛИЯНИЯ

9. Вставьте поля слияния: «Индекс», «Адрес», «Имя», «Отчество»

10. Для замены полей на соответствующие данные из базы данных воспользуйтесь кнопкой ПОСМОТРЕТЬ РЕЗУЛЬТАТЫ

11. Для перехода по записям можно воспользоваться соответствующими кнопками (рис. 25.1), расположенными на панели инструментов Просмотр результатов.

Объединение писем и сохранение

12. Для объединения писем в один документ выполните команду:

вкладка ленты Рассылки ► панель инструментов Завершение ►кнопка НАЙТИ И ОБЪЕДИНИТЬ ► Изменить отдельные документы ► объединить все записи.

В результате слияния у вас сформируются поздравительные письма для всех сотрудников предприятия.

13. Сохраните все 3 файла:

13.1. Оригинал со вставленными полями (документ, где 1 страница)

13.2. Источник данных

13.3. Итоговые письма в формате PDF
