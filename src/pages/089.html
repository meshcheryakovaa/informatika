2. Теоретическая справка

2.1. Что такое база данных

База данных (БД) — это организованная структура для хранения информации.

В реляционных БД данные представлены в виде таблиц.

Каждая таблица состоит из:

  • строк (записей) — конкретные объекты
  • столбцов (полей) — характеристики объектов

2.2. Основной SQL-запрос

Базовый синтаксис:

SELECT поле1, поле2
FROM таблица
WHERE условие;

2.3. Основные операторы

SELECT

Выбирает данные:

SELECT name
FROM Company;

WHERE

Фильтрация данных:

SELECT*
FROM Trip
WHERE town_from='Moscow';

LIKE

Поиск по шаблону:

SELECT name
FROM Passenger
WHERE name LIKE'%man';
  • % — любое количество символов
  • _ — один символ

COUNT()

Агрегатная функция для подсчёта:

SELECT COUNT(*)
FROM Trip;

С псевдонимом:

SELECT COUNT(*) AS count
FROM Trip;

JOIN

Соединение таблиц:

SELECT Company.name
FROM Company
JOIN TripON Company.id= Trip.company;

DISTINCT

Убирает дубликаты:

SELECT DISTINCT plane
FROM Trip;

3. Описание базы данных

В тренажёре используется база данных авиаперевозок. Основные таблицы:

  • Company — авиакомпании
  • Trip — рейсы
  • Passenger — пассажиры
  • Pass_in_trip — участие пассажиров в рейсах

Задание 1

SELECT name

Задание 2

SELECT *

WHERE town_from='Moscow';

Задание 3

Вывести имена людей, которые заканчиваются на "man"

SELECT name
FROM Passenger
WHERE name LIKE'%man';

Задание 4

Вывести количество рейсов, совершенных на TU-134

(обязательно использовать AS count)

SELECT COUNT(*) AS count
FROM Trip
WHERE plane='TU-134';

Задание 5

Какие компании совершали перелеты на Boeing

SELECT DISTINCT Company.name
FROM Company
JOIN Trip ON Company.id= Trip.company
WHERE Trip.plane LIKE 'Boeing%';

Вывести все названия самолётов, на которых можно улететь в Москву

FROM Trip
WHERE town_to='Moscow';

Вывести имена всех людей, которые есть в базе данных авиакомпаний
