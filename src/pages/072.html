ЛР18.1 Автозаполнение, формулы, функции, ссылки и работа с листами в Excel

1. Теоретическая часть

Автозаполнение — это встроенный механизм Excel, позволяющий быстро вводить типовые данные, разворачивать последовательности и копировать содержимое ячеек. Управление выполняется через маркер заполнения — маленький квадрат в правом нижнем углу выделенной ячейки.

1.1. Копирование данных

Если в ячейке находится одно значение (например: «Москва», «120»), то при протягивании маркера вниз/вверх/вбок Excel просто копирует его в соседние клетки.

1.2. Создание последовательностей

Excel распознаёт логические ряды:

  • числа: 1, 2, 3 → 4, 5, 6…
  • даты: 01.01.2025 → 02.01.2025…
  • дни недели: пн, вт, ср…
  • месяцы: янв, фев, мар…

Если задать первые два элемента, Excel продолжает последовательность с соответствующим шагом:

Например:

10, 20 → при протягивании: 30, 40, 50…

Автозаполнение ускоряет создание таблиц, нумерацию строк, заполнение календарей, шаблонов и повторяющихся данных.

Задание 6. Формулы

Формулы — основной механизм Excel для вычислений. Каждая формула должна начинаться со знака «=», иначе Excel будет воспринимать введённый текст как обычную строку, а не как вычисление.

6.1. Базовые арифметические операции

Excel поддерживает стандартные математические операторы:

  • + сложение
  • − вычитание
  • * умножение
  • / деление

Например:

=5+7

=A1*B1

=(A2+B2)/2

6.2. Относительные ссылки

При копировании формул Excel автоматически изменяет ссылки на ячейки относительно их положения.

Пример: формула в C1

=A1+B1

при протягивании вниз станет:

C2 → =A2+B2, C3 → =A3+B3, и так далее.

Это один из ключевых принципов автозаполнения при работе с расчётами.
