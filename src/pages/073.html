ЛР18. Интерфейс, навигация, работа с ячейками и базовое форматирование

Цель работы:

Освоить базовые навыки работы в Excel: открытие и сохранение файлов, ввод и редактирование данных, выделение диапазонов и базовое форматирование таблицы.

Задание 1. Интерфейс и навигация

  1. Откройте Microsoft Excel.
  1. Создайте новую рабочую книгу.
  1. Переименуйте лист Лист1 в "Данные".
  1. Создайте второй лист и назовите его "Отчёт".
  1. Переключитесь между листами несколько раз, чтобы освоить навигацию.
  1. Сохраните файл под именем "Фамилия Имя Группа Дата ЛР1".

Оформление шапки таблицы (A1–G1)

Учащиеся должны выполнить следующие действия:

1. Шрифт и начертание

  • Шрифт: Calibri (или любой стандартный школьный вариант)
  • Размер: 12 pt
  • Начертание: Полужирный

2. Выравнивание

  • По центру по горизонтали
  • По центру по вертикали
  • Перенос текста включить

3. Цвет и границы

  • Заливка: светло-голубой (например, голубой 15%–20%)
  • Цвет шрифта: тёмно-синий или чёрный
  • Границы:
    • внешняя толстая граница
    • внутренняя — тонкие линии

4. Высота строки

  • Установить высоту строки 1: 25–28 pt

Индивидуальное форматирование для каждого столбца

A — Название планеты

  • Формат: Текст
  • Выравнивание: по левому краю
  • Ширина столбца: 20–25

B — Масса (кг)

  • Формат числа: научный (например, 5,972E+24)

    или обычный, если ученик предпочитает.

  • Разделитель групп разрядов включить.
  • Выравнивание: по правому краю
  • Ширина столбца: 18–22

C — Диаметр (км)

  • Формат: Число, 0 знаков после запятой
  • Разделитель групп разрядов включить
  • Ширина столбца: 12–15

D — Период обращения (сут.)

  • Формат: Число, 3 знака после запятой
  • Пример: 365,260
  • Выравнивание: по правому краю
  • Ширина: 14–16

E — Дата открытия

  • Формат: Дата, краткий формат (дд.мм.гггг)
  • Выравнивание: по центру
  • Ширина: 12–15

F — Доля воды (%)

  • Формат: Процент, 0–1 знак после запятой
  • Пример: 71%
  • Выравнивание: по центру
  • Ширина: 10–12

G — Источник информации

  • Формат: Текст
  • Значение — название сайта (без ссылок для безопасности)
  • Выравнивание: по левому краю
  • Ширина: 20–30
