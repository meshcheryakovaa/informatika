Лекция 1. Назначение электронных таблиц. Основы работы в Excel

1. Значение и назначение электронных таблиц

Электронные таблицы — это программная среда для хранения данных, выполнения вычислений и анализа информации.

Excel использует двумерную структуру (строки × столбцы), что позволяет:

  • выполнять вычисления с использованием формул;
  • автоматизировать расчёты;
  • анализировать данные с помощью функций и диаграмм;
  • систематизировать большие массивы информации.

Электронные таблицы применяются в экономике, инженерии, науке, статистике — везде, где требуется числовая обработка данных.

2. Интерфейс Excel и основные элементы

2.1 Рабочая книга и лист

  • Рабочая книга (Workbook) — файл Excel.
  • Лист (Worksheet) — отдельная таблица внутри книги.

    Ученики должны понимать, что каждая книга может содержать множество листов.

2.2 Строки, столбцы и ячейки

  • Столбцы обозначаются буквами: A, B, C ...
  • Строки — числами: 1, 2, 3 ...
  • Адрес ячейки формируется как буква столбца + номер строки.

    Пример: B3, A10.

2.3 Панель инструментов

  • Вкладки: Главная, Вставка, Формулы, Данные, Вид — каждая содержит набор команд.
  • Строка формул показывает содержимое активной ячейки и формулы.

3. Типы данных в Excel

Excel различает несколько основных типов содержимого:

  1. Числа — используются в расчетах.
  1. Текст — служит для подписей и описаний.
  1. Дата/время — специальные форматы данных.
  1. Формулы — начинаются со знака «=».

Правильное распознавание типа данных важно, поскольку Excel автоматически применяет формат числа и интерпретирует значение.

4. Ввод и редактирование данных

4.1 Ввод

  • Кликнуть по ячейке → ввести данные → нажать Enter.
  • Редактирование: двойной щелчок или изменение текста в строке формул.

4.2 Автозаполнение

Маркер заполнения (маленький квадрат в правом нижнем углу ячейки) позволяет:

  • копировать данные;
  • заполнять последовательности (1,2,3…);
  • распространять формулы.

5. Формулы и базовые функции

Формула начинается со знака «=». Пример:

=A1 + B1

Ключевые понятия:

  • Относительные ссылки — изменяются при копировании (A1).
  • Абсолютные — фиксируются с помощью знака $ (например, $A$1).

    Это связано с механизмом ссылочной логики таблиц.

Базовые функции:

НазваниеПримерНазначение
SUM=SUM(A1:A5)Сумма диапазона
AVERAGE=AVERAGE(B1:B10)Среднее
MAX / MIN=MAX(C1:C20)Максимум/минимум
COUNT=COUNT(A1:A10)Кол-во числовых данных

6. Форматирование данных

Основные действия:

  • изменение шрифта, выравнивание;
  • формат числа: денежный, процент, дата;
  • объединение ячеек;
  • границы, цвет фона.

Форматирование не меняет значения, а только визуальное представление данных — это принципиально важно для корректной интерпретации таблиц.

7. Построение диаграмм (краткое знакомство)

На вводном уроке можно показать:

  1. Выделение диапазона данных.
  1. Вкладка Вставка → Диаграммы.
  1. Основные типы:
    • столбчатая,
    • линейная,
    • круговая.

Диаграммы служат для визуализации данных и упрощают анализ тенденций.
